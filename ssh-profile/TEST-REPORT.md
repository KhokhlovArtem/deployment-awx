# Испытания переносимого профиля — 2026-09-27

## Область

Тестовый сервер Ubuntu 24.04 после успешного bootstrap. Персональная учётная запись
`admakh`, ключ в SSH-agent WSL. Исходный логин, пароли, адрес сервера и закрытые ключи
в отчёт не включены. Утилита не читала `.env` и не использовала парольный доступ.

В текущем комплекте: `server_access.py`, схема профиля версии 1, `requirements.txt`,
`README.md`, `GUIDE.md` и `AGENTS.md`. Все эти файлы находятся рядом в ssh-profile.

## Границы результата

- Испытания подключений выполняли только команды проверки личности и sudo;
  конфигурация, пользователи и службы сервера этим этапом не изменялись.
- Системные журналы аутентификации могут отражать выполненные подключения.
- Реальные три принимающих проекта не открывались и не изменялись. Подтверждена
  переносимость в изолированном каталоге, но не совместимость с их playbook.
- Нужен работающий агент с соответствующим закрытым ключом на машине оператора.
- Только Linux/WSL для сетевых операций; native Windows, host CA/certificates,
  FIDO, bastion/proxy и первичное доверие через API провайдера не испытывались
  и не входят в текущую реализацию.
- Проверка sudo подтверждает конкретную read-only команду от root, а не анализ
  всех правил sudoers. Последующие проекты должны проверять результат своих задач.
- Профиль следует передавать доверенным способом и перепроверять при каждом
  использовании; сохранённый файл не является бессрочным свидетельством доступа.
