# Подготовка контроллера и сервера

Актуальная процедура находится в [README](../README.md#требования).

1. Подготовьте WSL2 Ubuntu и системные зависимости контроллера отдельно.
2. Настройте SSH public-key login и вручную проверьте fingerprint сервера из WSL.
3. Запустите `bash scripts/bootstrap.sh` в WSL: зависимости попадут в `.venv/`
   и `.ansible/collections/` этого проекта.
4. Запускайте установку с явными `--host` и `--user`, при необходимости `-K`.

Bootstrap не подготавливает сервер и не устанавливает системные пакеты на контроллере.
Удалённые Python/APT/venv подготавливаются install playbook после проверки ОС.
Старый `~/ansible-venv`, локальный inventory и загрузка `.env` больше не используются.
